# tower-sessions-toasty-store

[Toasty](https://github.com/tokio-rs/toasty) ORM session store for
[`tower-sessions`](https://github.com/maxcountryman/tower-sessions).
One store, many backends: SQLite, PostgreSQL, MySQL, Turso.

🚧 Work in progress — see `PLAN_tower-sessions-toasty.md` in the parent
workspace for design and status.
